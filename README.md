# LAMB Client Generator

Eina web estàtica dissenyada per a assignatures universitàries de **Gestió de Projectes**. Permet configurar, parametritzar i generar perfils d'assistents virtuals (*stakeholders* simulats) per entrenar l'alumnat en entrevistes d'extracció de requisits tècnics.

### Característiques principals
* **Integració nativa amb LAMB:** Generació i importació de perfils directament en format `.json` llestos per desplegar.
* **Compatibilitat amb LLMs comercials:** Funció directa de còpia de prompt per utilitzar en Gemini Gems o ChatGPT.
* **Matriu conductual:** Parametrització d'estil comunicatiu, criteris de decisió (cost, innovació, sostenibilitat) i autoritat jeràrquica.
* **Mode Avaluació Ocult:** Rúbrica automàtica integrada (0–60 punts) per qualificar la gestió de la incertesa, l'extracció de dades custodiades i la professionalitat comunicativa.
